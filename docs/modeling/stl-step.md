# STL、STEP 与 STP

三维模型最常见的两种交换格式是 STL 和 STEP。本文简述它们之间的关系。

## 三种格式的区别

- **STEP 和 STP 是同一种格式**：都是国际标准 ISO 10303 定义的模型文件，`.stp` 只是早期为兼容三个字母扩展名而用的写法，内容和 `.step` 完全一样，直接改扩展名即可；
- **STL 是另一种格式**：只用大量**三角形**拼出物体的外表面。

| 对比项 | STL | STEP / STP |
|---|---|---|
| 描述方式 | 三角网格，曲面由很多小三角形近似 | 精确的几何曲面（圆就是真正的圆） |
| 包含信息 | 只有外形，没有单位、颜色、装配关系 | 有单位、颜色，可以包含多个零件和装配结构 |
| 能否再编辑 | 基本不能，只能当作一整块网格 | 可以在 CAD 软件中继续修改、测量 |
| 文件大小 | 曲面越精细，三角形越多，文件越大 | 较小 |
| 典型用途 | 3D 打印、仿真（如 MuJoCo 的网格模型）、渲染 | 在不同 CAD 软件之间交换模型，如 SolidWorks、Onshape、KiCad 的 3D 元件模型 |

## 互相转换

```text
STEP / STP ──── 导出（三角化，容易）────► STL
           ◄─── 转换（很难还原成真正的曲面）──
```

- **STEP → STL**：很容易。CAD 软件导出时把曲面切成三角形，可以选择精度，精度越高越平滑、文件越大；
- **STL → STEP**：虽然有工具能转换，但得到的只是"三角形拼成的面"，不会变回真正的圆柱、圆孔，基本无法再编辑。

所以**设计时保存 STEP，需要打印或仿真时再导出 STL**。拿到别人的模型时，优先要 STEP 文件。
