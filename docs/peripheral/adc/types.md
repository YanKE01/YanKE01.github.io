# 常见的 ADC 类型

ADC（Analog-to-Digital Converter）把连续的模拟电压转换成数字量。MCU 里自带的通常是 SAR ADC，但在音频、示波器、万用表里用的往往是其他架构。本文介绍最常见的五种：SAR、Flash、流水线、Σ-Δ 和双积分。

## 五种 ADC 一览

| 类型 | 原理 | 典型分辨率 | 典型速率 | 常见应用 |
|---|---|---|---|---|
| **Flash（闪速）** | 2ᴺ−1 个比较器同时比较，一步出结果 | 6～8 bit | 数百 MS/s～数 GS/s | 示波器、高速通信 |
| **流水线（Pipeline）** | 多级串联，每级解出几位，把余量传给下一级 | 10～16 bit | 数十 MS/s～1 GS/s 左右 | 通信基带、视频、超声 |
| **SAR（逐次逼近）** | 二分查找，每个时钟确定 1 位 | 8～18 bit | 数 kS/s～数 MS/s | MCU 内置 ADC、传感器采集 |
| **Σ-Δ（Sigma-Delta）** | 过采样 + 噪声整形 + 数字滤波 | 16～24 bit 及以上 | 数 S/s～数 MS/s | 音频、称重、精密测量 |
| **双积分（Dual-Slope）** | 对输入积分固定时间，再用基准反向积分，数时间 | 高精度 | 每秒几次～几十次 | 数字万用表、仪表 |

可以按"速度和精度的取舍"来记：Flash 最快但位数最少，双积分最慢但最准，SAR 和 Σ-Δ 处在中间，也是嵌入式里最常见的两种。

## SAR：逐次逼近

SAR（Successive Approximation Register）ADC 由**采样保持电路、比较器、DAC 和逐次逼近寄存器**组成，转换过程就是**二分查找**：

1. 采样保持电路把输入电压 $V_{in}$ 锁住；
2. 先把最高位置 1，DAC 输出 $V_{ref}/2$，比较器判断 $V_{in}$ 是否大于它，决定这一位保留 1 还是改成 0；
3. 依次确定下一位，N 位 ADC 需要 N 次比较。

例如 3 bit、$V_{ref}$ = 8 V、$V_{in}$ = 5.3 V：先试 100（4 V）→ 大于，保留；再试 110（6 V）→ 小于，清 0；再试 101（5 V）→ 大于，保留，结果为 **101**。

SAR 结构简单、功耗低、**没有转换延迟**（这次采样的结果这次就出来），所以几乎所有 MCU 都内置 SAR ADC，例如 ESP32 系列的 ADC。

## Σ-Δ：过采样换精度

Σ-Δ ADC 的核心是一个**很粗的量化器**（常常只有 1 bit），靠以下两点换来高分辨率：

- **过采样**：以远高于信号带宽的频率采样（例如音频带宽 20 kHz，调制器跑在几 MHz），量化噪声被摊到很宽的频带上；
- **噪声整形**：调制器的反馈环路把量化噪声推到高频，信号所在的低频段噪声很小。

之后数字**抽取滤波器**滤掉高频噪声并降低数据率，输出 16～24 bit 的结果。

代价是**速度和延迟**：数字滤波需要多个采样周期，输出有固定延迟，不适合多路快速切换通道的场合。音频 Codec 里的 ADC 基本都是 Σ-Δ 结构。

## Flash 与流水线：追求速度

- **Flash ADC**：N 位需要 2ᴺ−1 个比较器，所有比较器**同时**和输入比较，一个时钟就出结果。比较器数量随位数指数增长（8 bit 就要 255 个），面积和功耗很大，所以位数做不高。
- **流水线 ADC**：把转换拆成多级，每级用一个小的 Flash ADC 解出几位，再把剩下的余量放大后交给下一级。各级像流水线一样同时处理不同的采样点，**吞吐率高**，但结果要过几个时钟才出来，有固定的流水线延迟。

## 双积分：慢但准

双积分 ADC 分两步：

1. 对输入电压积分**固定的时间**；
2. 换成极性相反的基准电压反向积分，计数**回到零所需的时间**，这个时间与输入电压成正比。

结果只取决于两段时间之比，与积分电容、时钟的绝对精度无关，所以很准。若积分时间取工频周期的整数倍（如 20 ms），50 Hz 干扰会被积分抵消。缺点是很慢，每秒只能转换几次到几十次，常用于数字万用表。

## Q: 实际项目中怎么选？

| 需求 | 推荐 |
|---|---|
| MCU 采集电池电压、传感器、多通道轮询 | SAR（通常直接用 MCU 内置的） |
| 音频录音、麦克风 | Σ-Δ（音频 Codec） |
| 称重、热电偶、高精度慢速测量 | Σ-Δ 或双积分 |
| 软件无线电、高速数据采集 | 流水线 |
| 示波器、GS/s 级采样 | Flash 或交织（多个 ADC 轮流采样） |
