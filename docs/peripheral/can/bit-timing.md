# CAN 位时间参数

配置 CAN 控制器时，除了波特率，还要设置一组**位时间参数**：BRP、TSEG1、TSEG2、SJW。它们决定一个位被分成多少段、在哪一刻采样、如何与其他节点保持同步。参数设置不当，轻则通信距离受限，重则节点之间互相报错、频繁进入错误被动或总线关闭状态。

## 概述

| 参数 | 含义 | 单位 |
|---|---|---|
| **$f_{clk}$** | CAN 控制器的输入时钟频率，即分频之前的时钟，例如 ESP32-S3 的 TWAI 使用 80 MHz 的 APB 时钟 | Hz |
| **Tq**（Time Quantum） | 时间份额，位时间的最小单位 | 由时钟分频得到 |
| **BRP**（Baud Rate Prescaler） | 时钟分频系数：$T_q = \mathrm{BRP} / f_{clk}$ | — |
| **Sync_Seg** | 同步段，固定 1 Tq | Tq |
| **TSEG1** | 传播段 + 相位缓冲段 1（Prop_Seg + Phase_Seg1） | Tq |
| **TSEG2** | 相位缓冲段 2（Phase_Seg2） | Tq |
| **SJW**（Synchronization Jump Width） | 重同步时每次最多调整的长度 | Tq |

常用公式：

$$
\begin{aligned}
T_q &= \frac{\mathrm{BRP}}{f_{clk}} \\
T_{bit} &= (1 + \mathrm{TSEG1} + \mathrm{TSEG2}) \times T_q \\
\text{位速率} &= \frac{f_{clk}}{\mathrm{BRP} \times (1 + \mathrm{TSEG1} + \mathrm{TSEG2})} \\
\text{采样点} &= \frac{1 + \mathrm{TSEG1}}{1 + \mathrm{TSEG1} + \mathrm{TSEG2}}
\end{aligned}
$$

其中 $f_{clk}$ 是 CAN 控制器的输入时钟频率，$T_q$ 是时间份额，$T_{bit}$ 是一个位的时间。$f_{clk}$ 由芯片的时钟树决定，不同芯片、不同时钟源配置下可能不同，需要查阅芯片技术参考手册；控制器先把它按 BRP 分频得到 $T_q$，再用 $T_q$ 拼出整个位。

## Q: CAN 总线上的信号是什么样的？

CAN 总线由两根线组成：**CAN_H** 和 **CAN_L**，通常为双绞线，总线两端各接一个 120 Ω 的终端电阻。CAN 用两根线之间的**电压差**表示逻辑电平，总线只有两种状态：

| 状态 | 逻辑值 | CAN_H | CAN_L | 差分电压 CAN_H − CAN_L |
|---|---|---|---|---|
| **隐性**（Recessive） | 1 | 约 2.5 V | 约 2.5 V | 约 0 V |
| **显性**（Dominant） | 0 | 约 3.5 V | 约 1.5 V | 约 2 V |

收发器按差分电压判断状态：差分电压大于 0.9 V 判为显性，小于 0.5 V 判为隐性（ISO 11898-2 高速 CAN）。在 MCU 一侧，CAN 控制器与收发器之间只有 TXD、RXD 两根普通的逻辑电平信号，TXD 为低电平时收发器驱动显性。

下图是总线上连续传输 `1 0 0 1 1 0 1` 时 CAN_H、CAN_L 的示意波形，中间的电平表示约 2.5 V：显性时两根线向相反方向分开，隐性时回到同一电平。

```wavedrom
{
  signal: [
    { name: '位', wave: '3443343', data: ['1', '0', '0', '1', '1', '0', '1'] },
    { name: 'CAN_H', wave: 'z1.z.1z' },
    { name: 'CAN_L', wave: 'z0.z.0z' },
  ],
  config: { hscale: 2 },
}
```

从波形可以看出 CAN 信号的几个特点：

- **显性覆盖隐性**：只要有一个节点发送显性，总线就是显性；只有所有节点都发送隐性时，总线才是隐性。仲裁、应答和错误帧都依赖这一点；
- **没有时钟线**：每一位只是在一个位时间内保持一个电平（NRZ 编码），收发双方各自按约定的位速率计时；
- **相同的位之间没有跳变**：连续发送多个相同的位时，总线电平一直不变。为保证帧中经常出现跳变沿，CAN 规定在帧起始到 CRC 序列之间，连续 5 个相同的位之后插入 1 个相反的位，称为**位填充**。

## Q: 没有时钟线，接收方怎么知道何时读取每一位？

收发双方事先配置了相同的位速率，接收方知道一个位应该持续多长时间。它利用总线上**从隐性到显性的跳变沿**对齐位的起点，然后按位时间计时，在每一位中**固定的某一时刻**读取总线电平，这个时刻就是**采样点**。下图中标“采样”的竖线是每一位的采样点，位于每一位的 75% 处；标“同步”的竖线是隐性到显性的跳变沿：

```wavedrom
{
  signal: [
    { name: '位', wave: '3...4...4...3...', data: ['1', '0', '0', '1'] },
    { name: 'CAN_H', wave: 'z...1.......z...', node: '...AS..B...C...D' },
    { name: 'CAN_L', wave: 'z...0.......z...', node: '...ET..F...G...H' },
  ],
  edge: ['S-T 同步', 'A-E 采样', 'B-F 采样', 'C-G 采样', 'D-H 采样'],
  config: { hscale: 1 },
}
```

可以看到，**跳变沿和采样点是两回事**：

- **跳变沿用来同步**：它告诉接收方"一个新的位从这里开始"，接收方据此校准自己的计时。CAN 只用隐性到显性的跳变沿（图中位 1 到位 0 处）做同步，显性到隐性的跳变沿（位 0 到位 1 处）边沿较慢，不用于同步；
- **采样点用来读数据**：在跳变之后、电平已经稳定的时刻读取。

这与 I2C 的情况其实是一致的：I2C 在 SCL 上升沿采样，但那是**时钟线**的跳变，此时数据线 SDA 早已稳定；CAN 没有时钟线，总线上的跳变本身就是数据在变化，正处于不稳定的时刻，所以不能在跳变处采样。

采样点不放在位的开头，而是放在位的**中后部**（通常为 75%～87.5%），原因是位的开头附近电平并不可靠：

- **信号有延迟**：信号经过收发器和总线到达接收方需要时间，离得越远，边沿到得越晚；
- **边沿不陡**：边沿有上升、下降时间，还可能有振铃，跳变后需要一段时间才稳定；
- **时钟有误差**：各节点的晶振频率略有差异，误差会随时间累积，每个位的实际起点会慢慢偏移。

为了精确描述"边沿应该出现在哪里、给延迟留多少时间、采样点在哪里、误差怎样修正"，CAN 把一个位再细分成若干个更小的时间单位，并划分为几个段，这就是下面要介绍的位时间参数。

## Q: CAN 的一个位是怎样划分的？

CAN 控制器内部并不把一个位当作一个整体，而是先把时钟分频得到**时间份额 Tq**，再用若干个 Tq 拼成一个位。ISO 11898-1 把一个位分为 4 段：

| 段 | 长度（经典 CAN） | 作用 |
|---|---|---|
| **Sync_Seg**（同步段） | 固定 1 Tq | 期望边沿出现在这一段内，用于同步 |
| **Prop_Seg**（传播段） | 1～8 Tq | 补偿信号在总线和收发器上的往返延迟 |
| **Phase_Seg1**（相位缓冲段 1） | 1～8 Tq | 可以在重同步时**加长**，补偿边沿来晚 |
| **Phase_Seg2**（相位缓冲段 2） | 不小于信息处理时间（≤ 2 Tq） | 可以在重同步时**缩短**，补偿边沿来早 |

一个位总共 8～25 个 Tq。**采样点**位于 Phase_Seg1 与 Phase_Seg2 之间，控制器在这一刻读取总线电平，作为这一位的值。

大多数 CAN 控制器把 Prop_Seg 和 Phase_Seg1 合并为一个寄存器 **TSEG1**，Phase_Seg2 对应 **TSEG2**。以 ESP32-S3 在 500 kbit/s 下的预设为例（Tq = 125 ns，共 16 Tq）：

```wavedrom
{
  signal: [
    { name: 'Tq', wave: 'p...............', node: '............A...' },
    { name: '标准划分', wave: '34.....5....6...', data: ['Sync', 'Prop_Seg', 'Phase_Seg1', 'Phase_Seg2'] },
    { name: '寄存器', wave: '34..........6...', node: '............B...', data: ['Sync', 'TSEG1 = 11', 'TSEG2 = 4'] },
  ],
  edge: ['A-B 采样点 75%'],
  config: { hscale: 1 },
}
```

图中 TSEG1 的 11 个 Tq 由 Prop_Seg 和 Phase_Seg1 共同组成，具体如何划分由控制器内部处理，配置时只需要给出总长度。

## Q: 每一位都有同步段、传播段这些吗？它们会被发送到总线上吗？

**每一位都有**。一帧中的每一位，从帧起始（SOF）到帧结束（EOF），包括位填充插入的位，都按同样的方式划分为 Sync_Seg、Prop_Seg、Phase_Seg1、Phase_Seg2，各段长度由配置决定，所有位都一样。

但这些段**不是发送到总线上的信号**，而是每个节点在内部给一个位划分的**时间刻度**。总线上看到的只是这一位的电平，在整个位时间内保持不变；电平只可能在一位开始的同步段内变化。下面是连续 3 个位的示意，每位 8 个 Tq（Sync_Seg 1 + Prop_Seg 3 + Phase_Seg1 2 + Phase_Seg2 2）：

```wavedrom
{
  signal: [
    { name: '位', wave: '3.......4.......4.......', data: ['1', '0', '0'] },
    { name: 'CAN_H', wave: 'z.......1...............' },
    { name: 'CAN_L', wave: 'z.......0...............' },
    { name: '时间刻度', wave: '34..5.6.34..5.6.34..5.6.', data: ['S', 'Prop', 'PS1', 'PS2', 'S', 'Prop', 'PS1', 'PS2', 'S', 'Prop', 'PS1', 'PS2'] },
  ],
  config: { hscale: 1 },
}
```

各节点按这个刻度做三件事：

- **发送方**：在每一位的同步段开始时，把输出切换为这一位的值；如果和上一位相同，就保持不变；
- **接收方**：期望跳变沿出现在同步段内；跳变沿来早或来晚时，通过调整相位缓冲段重新对齐（见后文重同步）；
- **所有节点**：在 Phase_Seg1 结束、Phase_Seg2 开始的采样点读取总线电平。发送方也会读回自己发出的位，用于仲裁和位错误检测。

所以"同步段"并不意味着每一位都有一个同步脉冲。如图中第 2、3 位都是 0，两者之间总线上没有任何跳变，接收方只是按刻度继续计时，在第 3 位的采样点照常读取电平。

## Q: 位速率和采样点怎样计算？

以 ESP32-S3 的 500 kbit/s 预设为例：时钟 80 MHz，Tq 分辨率 8 MHz（BRP = 10），TSEG1 = 11，TSEG2 = 4：

$$
\begin{aligned}
T_q &= \frac{1}{8\ \mathrm{MHz}} = 125\ \mathrm{ns} \\
T_{bit} &= (1 + 11 + 4) \times 125\ \mathrm{ns} = 16 \times 125\ \mathrm{ns} = 2\ \mu\mathrm{s} \\
\text{位速率} &= \frac{1}{2\ \mu\mathrm{s}} = 500\ \mathrm{kbit/s} \\
\text{采样点} &= \frac{1 + 11}{16} = 75\%
\end{aligned}
$$

设置参数的一般步骤：

1. **确定每位的 Tq 数**：$f_{clk}$ / 位速率必须能被 BRP 整除，商就是每位的 Tq 数，应在 8～25 之间。Tq 数越多，采样点可以设置得越精细；
2. **确定采样点**，算出 TSEG2：TSEG2 = Tq 数 × (1 − 采样点)，取整；
3. **TSEG1 = Tq 数 − 1 − TSEG2**；
4. **SJW** 取 TSEG2 允许范围内尽量大的值，经典 CAN 最大为 4。

例如希望 ESP32-S3 以 500 kbit/s、采样点 87.5% 工作：80 MHz / 500 kbit/s = 160，取 BRP = 10 得到 16 Tq；TSEG2 = 16 × 12.5% = 2，TSEG1 = 16 − 1 − 2 = 13，采样点 (1 + 13) / 16 = 87.5%。

## Q: 采样点应该设在哪里？

采样点越**靠后**，留给信号传播和边沿稳定的时间越多，总线可以更长；但采样点后面留给 Phase_Seg2 的时间越少，能容忍的时钟误差就越小。实际中采样点一般设在 **75%～87.5%**。

| 位速率 | 常用采样点 |
|---|---|
| ≤ 500 kbit/s | 87.5% |
| 500 kbit/s | 80%～87.5% |
| 800 kbit/s ～ 1 Mbit/s | 75%～80% |

CANopen（CiA 301）、J1939 等高层协议对采样点也有各自的推荐值，在这些系统中应以协议规定为准。

::: warning 同一网络中的采样点应保持一致
位速率相同、但采样点相差较大的节点，在总线较长或时钟有误差时更容易出现位错误。调试多个厂商设备组网的问题时，首先要核对的就是各节点的采样点。
:::

ESP-IDF 新版 TWAI 驱动在未指定采样点时，会按位速率自动选择：≥ 800 kbit/s 取 75%，≥ 500 kbit/s 取 80%，更低的速率取 87.5%。

## Q: 什么是硬同步和重同步？SJW 有什么作用？

CAN 没有单独的时钟线，各节点用自己的晶振计时，时间长了会产生偏差。节点通过**总线上从隐性到显性的跳变沿**来校准自己的位时间，分为两种：

- **硬同步**：在帧起始（SOF）的下降沿，所有节点直接把位时间重新对齐，下一个 Tq 就从 Sync_Seg 开始；
- **重同步**：帧中间的每个隐性到显性的跳变沿，如果没有落在 Sync_Seg 内，节点就调整当前位的长度：
  - 边沿**来晚**了（落在同步段之后、采样点之前，即 Prop_Seg 或 Phase_Seg1 中）：**加长 Phase_Seg1**，把采样点往后推；
  - 边沿**来早**了（落在上一位的采样点之后，即上一位的 Phase_Seg2 中）：**缩短 Phase_Seg2**，让下一位提前开始。

**SJW** 规定了每次重同步最多能加长或缩短几个 Tq。SJW 越大，节点追上其他节点的速度越快，对时钟误差的容忍度越高；但 SJW 不能大于 Phase_Seg1 和 Phase_Seg2，经典 CAN 中最大为 4 Tq。

CAN 使用**位填充**（连续 5 个相同的位之后插入 1 个相反的位），保证在填充范围内（从帧起始到 CRC 序列），最多每 10 位就会出现一个隐性到显性的跳变沿，重同步才有机会进行。CRC 界定符、ACK 段、帧结束和总线空闲期间不做位填充。

## Q: 传播段要设置多长？和总线长度有什么关系？

CAN 依靠**仲裁**决定谁占用总线：在仲裁段（帧起始之后的标识符等位）中，发送节点在发送每一位的同时读回总线电平，如果发出隐性位却读到显性位，就知道有优先级更高的节点在发送，于是退出仲裁。（在仲裁段以外，这种情况有不同含义：在 ACK 槽中表示接收方正常应答，在数据段中则是位错误。）这要求在采样点之前，信号能在**最远的两个节点之间走一个来回**：

$$
\mathrm{Prop\_Seg} \times T_q \ge 2 \times (t_{tx} + t_{bus} + t_{rx})
$$

其中 $\mathrm{Prop\_Seg}$ 为传播段的 Tq 数，$t_{tx}$、$t_{rx}$ 为收发器的发送、接收延迟，$t_{bus}$ 为信号在总线上的传播延迟。

- 双绞线上的传播延迟约为 **5 ns/m**；
- 收发器从发送到接收的环路延迟通常为一两百纳秒，具体见收发器数据手册。

位速率越高，一个位越短，留给往返延迟的时间就越少，总线就越短。常用的经验值：

| 位速率 | 最大总线长度（经验值） |
|---|---|
| 1 Mbit/s | 约 40 m |
| 500 kbit/s | 约 100 m |
| 250 kbit/s | 约 250 m |
| 125 kbit/s | 约 500 m |

如果需要更长的总线，应降低位速率，或者把采样点后移，留给传播段更多的时间。

## Q: CAN 对时钟精度有什么要求？

每个节点的时钟都有误差，误差在一帧中会不断累积，必须能在下一次重同步之前被 Phase_Seg 和 SJW 吸收。ISO 11898-1 给出了振荡器容差 Δf 需要同时满足的两个条件（各量以 Tq 为单位，NBT 为每位的 Tq 数）：

$$
\Delta f \le \frac{\min(\mathrm{Phase\_Seg1},\ \mathrm{Phase\_Seg2})}{2 \times (13 \times \mathrm{NBT} - \mathrm{Phase\_Seg2})}
$$

$$
\Delta f \le \frac{\mathrm{SJW}}{20 \times \mathrm{NBT}}
$$

从公式可以看出：

- **SJW 越大、相位缓冲段越长**，允许的时钟误差越大；
- 采样点越靠后，Phase_Seg2 越短，允许的时钟误差越小。

经典 CAN 在常用配置下允许的误差一般在千分之几到百分之一左右，普通晶振（几十 ppm）可以轻松满足；而芯片内部的 RC 振荡器误差通常达到百分之一甚至更大，**不适合作为 CAN 的时钟源**。

## Q: 在 ESP-IDF 中如何配置位时间？

ESP-IDF 新版 TWAI 驱动（`esp_twai.h`）只需要给出位速率，采样点可选；驱动会根据时钟自动计算 BRP、TSEG1、TSEG2：

```c
twai_onchip_node_config_t node_config = {
    .io_cfg = {
        .tx = GPIO_NUM_4,
        .rx = GPIO_NUM_5,
        .quanta_clk_out = GPIO_NUM_NC,
        .bus_off_indicator = GPIO_NUM_NC,
    },
    .bit_timing = {
        .bitrate = 500000,   // 500 kbit/s
        .sp_permill = 875,   // 采样点 87.5%，填 0 则按位速率自动选择
    },
    .tx_queue_depth = 5,
};
```

旧版驱动使用预设宏，例如 `TWAI_TIMING_CONFIG_500KBITS()`。同一个宏在不同芯片上的参数不同，因为各芯片 TWAI 的时钟源不同：

| 芯片 | 位速率 | Tq 分辨率 | TSEG1 | TSEG2 | SJW | 每位 Tq 数 | 采样点 |
|---|---|---|---|---|---|---|---|
| ESP32、ESP32-S3 等 | 500 kbit/s | 8 MHz | 11 | 4 | 2 | 16 | 75% |
| ESP32-S3 等 | 1 Mbit/s | 8 MHz | 5 | 2 | 1 | 8 | 75% |
| ESP32-C6、ESP32-P4 | 500 kbit/s | 10 MHz | 15 | 4 | 3 | 20 | 80% |
| ESP32-C6、ESP32-P4 | 1 Mbit/s | 20 MHz | 15 | 4 | 3 | 20 | 80% |

可以看到，ESP32-S3 在 1 Mbit/s 时每位只有 8 个 Tq，采样点只能以 12.5% 为步长调整，SJW 也只有 1，可调余地很小。与其他设备组网出现问题时，可以改用自定义参数，或者核对对方设备的采样点后再调整。

::: tip CAN FD
CAN FD 帧可以在数据段切换到更高的速率：帧中的 **BRS**（Bit Rate Switch）位为 1 时切换，为 0 时整帧使用仲裁段的速率。两个阶段**各有一套位时间参数**，ESP-IDF 中分别对应 `bit_timing` 和 `data_timing`。数据段速率很高时，收发器延迟可能超过一个位，还需要启用**发送延迟补偿**（TDC）。

CAN FD 需要硬件支持：ESP32-S3、ESP32-P4 等的 TWAI 只支持经典 CAN，设置 `data_timing` 无法开启 CAN FD；支持 CAN FD 的芯片（如 ESP32-C5）可查阅 ESP-IDF 文档。
