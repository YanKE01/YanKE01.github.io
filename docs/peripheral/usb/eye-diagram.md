# USB 高速眼图

做 USB 2.0 高速（High-Speed，480 Mbit/s）硬件时，信号质量通常用**眼图**来评估。本文以 Microchip USB3250 数据手册（DS00002142A）第 6.2 节引用的 USB 2.0 规范眼图模板为例，解释眼图上的 Level 1、Level 2 和 Point 1～6 各代表什么，以及怎样读懂一张眼图。

## 概述

| 项目 | 数值 | 说明 |
|---|---|---|
| 位速率 | 480 Mbit/s | 高速模式 |
| 单位间隔 UI | 1/480 MHz ≈ 2.083 ns | 一个比特的时间，眼图横轴以 % UI 表示 |
| 标称差分幅度 | ±400 mV | 单端高电平 360～440 mV，低电平 −10～10 mV（45 Ω 负载） |
| 发送模板（Template 1） | 眼内 ±300 mV，外限 ±475/±525 mV | 约束发送端，要求高 |
| 接收模板（Template 4） | 眼内 ±150 mV，外限 ±575 mV | 约束接收端，要求能接收劣化后的信号 |
| 接收灵敏度 | ≥ 100 mV | 差分输入 VDIHS |
| 静噪阈值 | < 100 mV 静噪，> 150 mV 解除静噪 | VHSSQ |

## Q: 什么是眼图？

**眼图**（Eye Diagram）是把一段很长的串行信号按**一个比特时间（UI）**切开，再把所有片段**叠加**显示在同一个窗口里得到的图形。示波器采集时以恢复出的时钟为基准，每一段都对齐到同一个 UI。

USB 高速信号是差分信号，眼图纵轴为差分电压 V(D+) − V(D−)。各种比特组合（0→1、1→0、1→1、0→0）叠在一起后，上下两条电平线与中间交叉的上升/下降沿围成一个形似眼睛的空白区域，这就是"眼"：

```usbeye

```

图中**蓝色线条**是叠加在一起的信号波形（这里是模拟生成的示意数据，并非实测），它们围出的中间空白区域就是"眼睛"。**红色部分**是 USB 规范规定的模板：中间的六边形和上下两条红色区域都是禁区，蓝线碰到它们就算不合格。后面两节分别解释上下的 Level 1/2 和中间的 Point 1～6。

读眼图主要看下面几个量，每一项都说明了"越大/越小"意味着什么：

| 看什么 | 怎么量 | 趋势 | 主要受什么影响 |
|---|---|---|---|
| **眼高**（纵向张开） | 比特中间位置，上下两条电平线之间最小的距离 | **越高越好**：离接收端的判决门限越远，噪声和衰减要更大才会让 0/1 判错 | 线路损耗、噪声、反射、驱动幅度不足 |
| **眼宽**（横向张开） | 0 V 处左右两个交叉点之间的距离 | **越宽越好**：可以正确采样的时间窗口越长，采样时刻偏一点也不会出错 | 抖动、码间串扰、边沿太慢 |
| **交叉点宽度** | 所有跳变过零位置在水平方向上的分布范围 | **越窄越好**：越宽说明每次跳变的时刻越不一致，即抖动越大，同时会直接让眼宽变小 | 时钟质量、电源噪声、串扰 |
| **电平线粗细** | 上下两条电平线在垂直方向上的厚度 | **越细越好**：越粗说明每个比特的电压越不稳定，同时会直接让眼高变小 | 噪声、码间串扰、反射造成的振铃 |
| **过冲** | 跳变后电压超出稳态的部分 | **越小越好**：过冲大说明有反射，严重时会超出 Level 1/2 | 阻抗不连续、走线分叉 |
| **上升/下降沿** | 边沿从低到高、从高到低所需的时间 | **适中**：太慢会切进六边形，太快会加剧过冲和电磁辐射 | 线上电容、驱动能力 |
| **与模板的距离**（裕量） | 波形离六边形和 Level 1/2 最近的距离 | **越大越好**：裕量大说明换一根更差的线、更长的走线也还能通过 | 以上所有因素 |

总结起来，**眼睛越"大"、线条越"细"，信号越好**。眼高和眼宽决定了接收端还有多少余量；交叉点和电平线的粗细则说明余量被什么吃掉了：横向变粗是抖动，纵向变粗是噪声和码间串扰。

眼图把成千上万个比特的统计特征放在一张图里，一眼就能看出信号最差时离出错还有多远。

## Q: 眼图在哪里测量？发送模板和接收模板分别对应什么？

USB 2.0 规范在信号路径上定义了 4 个测量点。以一块 ESP32-P4 开发板通过 Type-C 口接到电脑为例：

```usbeye
tp
```

| 测量点 | 规范中的位置 | 在这个例子里 |
|---|---|---|
| TP1 | 主机/集线器侧收发器引脚 | 电脑主板上 USB 控制器芯片的 D+/D− 引脚 |
| TP2 | 主机/集线器侧 A 型连接器 | 电脑上的 USB-A 插座 |
| TP3 | 设备侧连接器 | 开发板上的 Type-C 插座 |
| TP4 | 设备侧收发器引脚 | ESP32-P4 高速 USB PHY 的 D+/D− 引脚 |

对设备开发者来说，关心的是 **TP3，也就是自己板子上的 USB 插座**。从 ESP32-P4 引脚到 Type-C 插座之间的 PCB 走线、ESD 保护器件、共模电感等，都算作"设备"的一部分：

- 测**发送**眼图时，让 ESP32-P4 发送测试包，探头接在 Type-C 插座处，看波形是否满足 Template 1。走线太长、ESD 器件电容太大，都会在这里体现出来；
- 测**接收**能力时，由测试仪器在 Type-C 插座处送入一个已经劣化到 Template 4 程度的信号，看 ESP32-P4 能否正确接收。

规范用若干个**模板**（Template）描述不同位置、不同方向的眼图要求。与 PHY 关系最密切的两个是：

- **Template 1（发送）**：集线器在 TP2、或不带固定线缆的设备在 TP3 处测量的**发送波形**必须满足的模板；
- **Template 4（接收）**：在同样的位置把信号**施加给接收端**时，接收端必须能正确接收的模板，即接收灵敏度要求。

可以这样理解：发送模板是"发出去的信号至少要这么好"，接收模板是"信号经过线缆衰减后变成这么差，接收端也必须能收"。

::: tip 带固定线缆的设备
如果设备的线缆是固定在设备上不可拔插的（captive cable），测量点会移到线缆另一端的连接器，使用规范中的其他模板。一般开发板使用 Micro-B 或 Type-C 接口，属于不带固定线缆的情况。
:::

## Q: 眼图模板上的 Level 1 和 Level 2 是什么？

**Level 1 和 Level 2 是信号的上下外限**：所有波形都必须位于 Level 1 之下、Level 2 之上，不能越过图中上下两条红色区域。它们限制的是**过冲**和**过大的幅度**。

| 模板 | Level 1 | Level 2 |
|---|---|---|
| 发送（Template 1） | 跳变后的第一个 UI 内 +525 mV，其余 +475 mV | 跳变后的第一个 UI 内 −525 mV，其余 −475 mV |
| 接收（Template 4） | +575 mV | −575 mV |

几点说明：

- 标称幅度是 ±400 mV，Level 1/2 给它留出了上方的余量；
- 发送模板的外限分两档：信号**刚发生跳变的那一个 UI** 允许到 ±525 mV，用于容纳跳变后的过冲和振铃；**之后连续不变的比特**必须回落到 ±475 mV 以内。图中实线为 ±475 mV，虚线为 ±525 mV；
- 接收模板的外限放宽到 ±575 mV，接收端需要容忍更大的过冲。

超出 Level 1/2，通常意味着**反射**（阻抗不连续、走线分叉）或驱动电流偏大（例如 RREF 外部基准电阻取值不对，高速驱动电流约 17.78 mA，流过两端并联的 45 Ω 终端，即 22.5 Ω，产生 400 mV）。

## Q: Point 1～Point 6 围成的六边形是什么？

Point 1～6 围成眼睛中间的**六边形禁区**（Keep-out Region）：**任何一条波形都不能进入这个区域**。它规定了眼睛**至少**要张开多大。

```usbeye
rx
```

| 点 | 发送模板（Template 1） | 接收模板（Template 4） |
|---|---|---|
| Point 1 | 0 V，7.5% UI | 0 V，15% UI |
| Point 2 | 0 V，92.5% UI | 0 V，85% UI |
| Point 3 | +300 mV，37.5% UI | +150 mV，35% UI |
| Point 4 | +300 mV，62.5% UI | +150 mV，65% UI |
| Point 5 | −300 mV，37.5% UI | −150 mV，35% UI |
| Point 6 | −300 mV，62.5% UI | −150 mV，65% UI |

六边形的每一部分各有含义：

- **Point 1、Point 2（左右两个尖角，0 V）**：限制**眼宽**。波形过零点（交叉点）必须落在 Point 1 左侧或 Point 2 右侧。以发送模板为例，两侧各留 7.5% UI，即交叉点的总抖动范围约为 15% UI ≈ 312 ps；接收模板两侧各 15% UI，可容忍约 30% UI ≈ 625 ps 的抖动；
- **Point 3～6（上下两条平边）**：限制**眼高**。在比特中间的一段时间内（发送 37.5%～62.5% UI，接收 35%～65% UI），差分电压必须高于 +300 mV / +150 mV 或低于 −300 mV / −150 mV；
- **斜边**：连接尖角和平边，限制**上升/下降沿的速度**。边沿太慢，波形在比特中间还没有达到足够的电压，就会切进六边形。

::: info 眼高与静噪阈值
接收模板的眼高 ±150 mV 与接收器的解除静噪（Unsquelch）阈值 150 mV 一致：高速接收器在差分电压低于 100 mV 时认为线上没有信号（静噪），高于 150 mV 时才认为有有效数据。眼睛如果小于这个高度，接收端可能根本不会开始接收。
:::

## Q: 为什么发送模板和接收模板的要求不一样？

因为两者之间隔着**线缆和连接器**。信号从发送端出来后，经过 PCB 走线、连接器和最长 5 m 的线缆，高频分量被衰减，边沿变缓，抖动和码间串扰增加，眼睛会变小。

| 对比项 | 发送（Template 1） | 接收（Template 4） |
|---|---|---|
| 眼高 | ±300 mV | ±150 mV |
| 眼宽（0 V 处） | 7.5%～92.5% UI，85% UI | 15%～85% UI，70% UI |
| 外限 | ±475/±525 mV | ±575 mV |

发送模板严格，保证信号"出门时足够好"；接收模板宽松，表示"经过最差的传输通道后，接收端仍然必须能正确接收"。两者之间的差距就是留给线缆和连接器的劣化预算。

## Q: 拿到一张眼图，应该怎样判断问题？

先看测试软件给出的**模板判定结果（Pass/Fail）**和**命中模板的次数（Mask Hits）**，然后根据波形碰到哪里来判断原因：

| 现象 | 碰到的位置 | 常见原因 |
|---|---|---|
| 上下线越过 Level 1/2 | 外限 | 阻抗不连续引起反射、驱动电流偏大（RREF 不对） |
| 平边被压进六边形 | Point 3～6 | 幅度不足：走线过长、损耗大、串联元件阻值过大、驱动电流偏小 |
| 交叉点很粗，碰到左右尖角 | Point 1、2 | 抖动大：时钟/晶振质量、电源噪声、串扰 |
| 斜边被切进六边形 | 斜边 | 边沿太慢：线上电容过大，例如 ESD 器件结电容大、走线过长 |
| 上下电平线很"粗" | 平边附近 | 码间串扰、反射造成的振铃、噪声 |
| 眼睛上下不对称 | — | D+/D− 不对称：走线长度不匹配、共模扼流圈或器件不平衡 |

对应的硬件改进方向一般是：差分走线做 **90 Ω** 差分阻抗控制，D+/D− 等长，减少过孔和分叉，选用低电容的 ESD 器件，检查 PHY 的 RREF 电阻和电源去耦。

## Q: 眼图是怎样测出来的？

1. **让设备进入测试模式**：主机向设备发送 `SET_FEATURE(TEST_MODE)` 标准请求，选择 **Test_Packet** 模式，设备会不停地重复发送规范规定的测试包。测试包包含各种比特组合，能覆盖最差情况；
2. **连接测量夹具**：使用 USB 测试夹具和差分探头，在规定的测量点（如设备侧 TP3）测量 D+、D−；
3. **示波器叠加生成眼图**：示波器以恢复出的时钟为基准，把采集到的波形按 UI 叠加，再套上对应的模板；
4. **判定结果**：示波器的 USB 一致性测试软件自动检查是否碰到模板，并给出上升/下降时间、抖动、眼高等参数。

::: tip 测量带宽
USB 高速信号的边沿约为几百皮秒（数据手册规定差分上升/下降时间不小于 500 ps），测量时示波器和探头带宽通常需要 2 GHz 以上，否则示波器自身会让边沿变缓、眼睛变小。
:::

全速（Full-Speed，12 Mbit/s）信号的速率低得多，主要关注上升/下降时间（4～20 ns）和交叉电压（1.3～2.0 V）等参数；工程中提到"USB 眼图"时，一般指的是高速眼图。
